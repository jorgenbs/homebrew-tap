# jorgenbs/homebrew-tap

Personal Homebrew tap.

```sh
brew install --cask jorgenbs/tap/clipboard-history
```

| Cask | Description |
| --- | --- |
| [`clipboard-history`](https://github.com/jorgenbs/clipboard-history) | Menu bar clipboard history with search, preview and auto-paste |

Casks are updated automatically by each project's release workflow.
